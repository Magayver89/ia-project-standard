# Specs

Cada funcionalidade deve ter uma pasta própria:

```text
specs/NNN-nome-da-feature/
```

Use `templates/feature/` como base.

Fluxo recomendado por feature:

```text
SPEC → CLARIFICAÇÃO → RESEARCH (se necessário) → PLAN → TASKS → IMPLEMENTAÇÃO → VALIDAÇÃO → MEMORY
```

A pasta `000-example-feature/` é apenas um exemplo preenchido e pode ser removida quando o projeto real estiver inicializado.
